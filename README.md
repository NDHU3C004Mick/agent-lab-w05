# Agent Lab W05

課堂練習成果彙整。所有資料為教學模擬，無姓名、學號或私人帳號資訊。

提交順序：A → B v1 → B v2 → D → Record。

- `A.md`：A 題 input 盤點與整理計畫。這次只完成第一階段讀取；沒有建立 A 題 output。
- `activities.json`、`B-v1.html`：B 題原始活動資料與第一版離線頁面。
- `B-v2.html`：加入四種可選風格的單頁版本。
- `D.md`：對刻意錯誤模擬計畫的退回意見。
- `record.md`：依實際對話整理的工作紀錄，不是學生個人自述；請自行檢查及補上個人觀察。
- `submission-template.md`：課堂提供的學習紀錄空白模板。
